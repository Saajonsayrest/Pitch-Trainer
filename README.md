# Pitch Trainer

An ear-training app for Flutter. It plays an interval, a chord, a scale or a chord progression, and you name what you hear. Each lesson first teaches the sound, then lets you practise with help, then gives a short test.

> **A study project.** This is a clone of an existing ear-training app, built to experiment, explore and learn how such apps work. It is not affiliated with that app or its makers. It has its own code, colors, text and synthesized sounds. No audio, images or code were taken from the original. It is not for sale and is not on any app store.

## What it does

- Five trainers: intervals, chords, scales, home note and chord progressions.
- Lessons in three steps: learn (memory tips, side by side), practise with a speaker button on every answer, then a scored test.
- Checkpoints and final exams, a daily session, a streak and stats.
- No account, no ads, no tracking. Progress stays on the phone.
- All sounds are made in code, so there are no audio files.

## Run it

```
cd app
flutter pub get
flutter run
flutter test
```
